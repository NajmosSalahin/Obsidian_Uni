**Trial:** A trial is an experiment that results in one or more outcomes.

**Experiment:** An experiment is an act that can be repeated under given conditions.

**Sample Space:** The set of all possible outcomes of a trial or experiment.

**Event:** An event is a subset of the sample space.

**Equally Likely:** Outcomes are said to be equally likely if each has the same probability of occurring.

**Mutually Exclusive:** Two or more events are mutually exclusive (disjoint) if they cannot occur at the same time.

**Independent Events**: Independent Events are events where the occurrence of one does not change the probability of the other.

**Set:** A collection of distinct, well-defined objects.

**Subset:** A set $A$ is called a subset of $B$ if every element of $A$ is also in $B$.

**Universal Set:** The set that contains all objects under consideration in a given context.

**Empty Set (Null Set):** A set with no elements.

**Disjoint Sets:** Two sets are disjoint if they have no elements in common.

**Power Set:** The set of all subsets of a set $A$.

**Product Set (Cartesian Product):** For sets $A$ and $B$, the product set is $A\times B=\{(a,b)|a\in A, b\in B\}$.

**Countable Set:** A set whose elements can be put into one-to-one correspondence with natural numbers.

**Uncountable Set:** A set that cannot be listed or paired with natural numbers.

**Real Line:** The set of all real numbers represented as points on a straight line is called a Real Line.

**Venn Diagram:** A pictorial representation of sets and their relationships using closed curves inside a rectangle.

**Finite Set:** A set with a limited number of elements.

**Infinite Set:** A set with an unlimited number of elements.

**Equal Sets:** Sets that contain the exact same elements.

**Equivalent Sets:** Sets that have different elements but the same number of elements.

**Overlapping Sets:** Sets that have at least one common element.

**The Axioms of Probability:** Non-Negativity: $P(A)\ge0$ for any event A
						   Normalization: $P(S)=1$, where S is the sample space
                           Countable-Additivity: For two disjoint events, $P(A\cup B)=P(A)+P(B)$
