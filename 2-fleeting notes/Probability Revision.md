3.Probability Space: The probability space is a mathematical triplet$(\Omega, \mathcal{F}, P)$ that presents a model for a particular class of real world solutions.
   i. A sample space, $\Omega$ , which is the set of all possible outcomes of an experiment.
   ii. the $\sigma-$ algebra $\mathcal{F}$ $\subseteq$ $2^{\Omega}$ , is a collection of all the events
   iii. The probability measure $P$ is a function returning an event's probability. Thus $P$ is a function $P: \mathcal{F} \to [0,1]$ .
