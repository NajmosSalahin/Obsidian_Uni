## How to Contribute (All via Browser)

### Step 1: Fork the Repo
Go to the repo → click the **Fork** button

📎 Repo: [https://github.com/NajmosSalahin/Barnackle](https://github.com/NajmosSalahin/Barnackle)  
📎 Fork: [https://github.com/NajmosSalahin/Barnackle/fork](https://github.com/NajmosSalahin/Barnackle/fork)

### Step 2: Create Your Folder
- Go to `1.2 self notes/` in your fork
- Click **Add file → Create new file**
- In the filename box, type: `Your Name/welcome.md`
- In the content area, type: `# Notes by "Your Name"`
- Click **Commit new file**

### Step 3: Upload Your Notes
- Go inside your `Your Name/` folder
- Click **Add file → Upload files**
- Drag & drop your files, click **Commit changes**

### Step 4: Open a Pull Request
- Go back to the original repo
- Click **Contribute → Open Pull Request**
- Give it a title, click **Create pull request**

Knock me on messaging app and I will review and merge.
